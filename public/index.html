ℹ️ À propos & Mentions légales

Agent IA de Gestion de Projet
Cet outil est conçu pour assister les gestionnaires de projet certifiés PMP dans la génération de livrables (Échéanciers, Registres de risques, Charte de projet, Analyses EVM/CPM). Les calculs mathématiques (Valeur Acquise, Chemin Critique) sont traités par le moteur local pour garantir une précision absolue, sans hallucination de l'IA.

Responsabilité de l'utilisateur (API IA)
L'utilisation de ce logiciel nécessite une clé API provenant de votre fournisseur d'IA (OpenAI, Google Gemini, OpenRouter) ou un moteur local (Ollama). L'utilisateur est seul responsable des coûts engendrés par l'utilisation de ces API Cloud, du respect des conditions d'utilisation de ces services tiers, et de la confidentialité des données de projet envoyées aux serveurs externes. Pour les projets sensibles, l'utilisation d'un modèle 100% local (Ollama) est fortement recommandée.
