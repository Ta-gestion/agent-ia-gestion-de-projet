🤖 Manuel d'Utilisation : Agent IA de Gestion de Projet

Bienvenue dans votre nouvel assistant de gestion de projet ! Cette application desktop vous permet de générer des livrables professionnels (Excel, Word, PDF) en exploitant la puissance de l'Intelligence Artificielle, tout en garantissant des calculs mathématiques exacts et le respect de vos modèles de documents d'entreprise.

1. Configuration de l'IA (Paramètres)

Avant d'utiliser l'application pour la première fois, vous devez connecter votre moteur d'Intelligence Artificielle. L'application est multi-IA, ce qui signifie que vous pouvez utiliser le fournisseur de votre choix.

  1. Ouvrez l'application et cliquez sur ⚙️ Paramètres du Moteur IA en haut de l'écran.
  2. Sélectionnez votre Type d'IA :
    • Google Gemini, OpenAI, OpenRouter (Cloud) : Nécessite une clé API.
    • Local (Ollama / LM Studio) : Nécessite d'avoir l'application installée sur votre machine (aucune clé API requise, 100% privé).
  3. Renseignez votre Clé API (si applicable) et le Nom du Modèle (ex: gemini-3.5-flash, gpt-4o, llama3.1).
  4. Cliquez sur Sauvegarder les paramètres.

2. Le Mode "Document Standard"

Ce mode vous permet de générer des documents de zéro, avec une mise en page professionnelle intégrée directement dans le système.

Documents disponibles :
  • Excel : Échéancier de projet (Gantt avec couleurs et jours ouvrés), Registre des risques, Registre des parties prenantes.
  • PDF : Charte de projet, Rapport d'analyse du Chemin Critique (CPM), Rapport de Valeur Acquise (EVM).

Comment l'utiliser :

  1. Dans la section 📝 Informations du projet, décrivez votre projet (Contexte, budget, équipe, dates, etc.).
  2. Dans la section ⚙️ Mode de génération, cliquez sur 📄 Document Standard.
  3. Dans la section 💬 Demande à l'IA, tapez ce que vous souhaitez générer (ex: Crée l'échéancier de projet avec 10 tâches).
  4. Cliquez sur Exécuter la demande.

3. Le Mode "Remplir mon modèle"

C'est la fonctionnalité la plus puissante : elle vous permet d'utiliser vos propres fichiers Excel (.xlsx) ou Word (.docx) avec votre charte graphique et vos formules complexes.

Étape 1 : Préparer votre modèle avec des balises

Dans votre fichier Excel ou Word, vous devez indiquer à l'application où insérer les données en utilisant des balises.

  • Pour un fichier Excel : Utilisez des accolades.
    • Dans une cellule : {{Nom_Projet}}
    • Dans une ligne de tableau (qui sera dupliquée) : {{Nom_Tache}}, {{Duree}}, etc.
  • Pour un fichier Word : Utilisez des crochets droits.
    • Dans un paragraphe : [Nom_Projet]
    • Dans une ligne de tableau : [Nom_Tache], [Jalon], etc.

Étape 2 : Uploader et exécuter

  1. Dans la section ⚙️ Mode de génération, cliquez sur 📋 Remplir mon modèle.
  2. Un champ d'upload apparaît. Sélectionnez votre fichier Excel ou Word.
  3. Remplissez les Informations du projet et votre Demande à l'IA (ex: Remplis ce registre de risques avec 5 risques liés au budget).
  4. Cliquez sur Exécuter la demande.

L'IA va analyser vos balises, générer les données, et un moteur Python injectera le tout dans votre fichier en dupliquant les lignes et en préservant vos couleurs et vos formules !

4. Récupération des fichiers générés

Une fois que l'IA a terminé son travail, deux boutons apparaîtront à l'écran :

  • ⬇️ Télécharger : Sauvegarde le fichier généré dans le dossier de téléchargement de votre navigateur (idéal pour l'envoyer par email ou l'archiver).
  • ➡️ Ouvrir : Ouvre directement le fichier dans votre logiciel par défaut (Excel, Word ou Adobe Reader). C'est l'option idéale pour consulter immédiatement le résultat sans aucune friction.

5. Bonnes pratiques et Astuces

Pour obtenir les meilleurs résultats possibles avec votre Agent IA, voici quelques règles d'or :

A. Soyez précis dans le contexte
L'IA ne connaît que ce que vous lui dites. Plus le bloc Informations du projet est complet (budget, équipe, contraintes, dates), plus les livrables seront pertinents.
B. Limitez le nombre de lignes pour les modèles locaux
Si vous utilisez une IA locale (Ollama) en mode "Remplir mon modèle", évitez de demander "Génère 50 risques". Les petits modèles locaux peuvent perdre le fil sur de trop gros volumes de texte. Demandez plutôt des lots de 5 à 10 lignes.
C. Respectez la syntaxe des balises
  • N'oubliez pas les doubles accolades pour Excel {{...}} et les crochets pour Word [...].
  • Évitez les espaces dans le nom des balises (Utilisez {{Nom_Tache}} et non {{Nom Tache}}).
  • N'utilisez pas d'accents dans les noms de balises pour garantir une reconnaissance parfaite (Utilisez {{Date_Fin}} au lieu de {{Date_Fin_Échéance}}).
D. Confiez les maths à l'application
Ne demandez pas à l'IA de calculer les dates de fin ou les indices de valeur acquise. Demandez-lui simplement de lister les tâches et leurs durées : l'application se chargera de faire les calculs exacts dans le fichier généré !
